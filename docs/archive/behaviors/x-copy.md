# x-copy

The copy behavior is documented in [copy.md](../../behaviors/copy.md): `x-copy` copies `copy-text`, or the text of the element matched by `copyTarget`, to the clipboard when the element is clicked. For a button placed in the corner of a code block, see [copybutton.md](../../behaviors/copybutton.md).

- **Demo:** [Interactive & Utility demos](../../../demos/site/interactive.html#copy-copy).
- **Schema:** [copy.schema.json](../../../src/wb-models/copy.schema.json).
