# x-draggable

The drag behavior is documented in [draggable.md](../../behaviors/draggable.md): `x-draggable` lets the user move an element, with `axis` to lock the direction and `handle` to limit where a drag can start. For a whole card that drags, see [carddraggable.md](../../behaviors/carddraggable.md).

- **Demo:** [Interactive & Utility demos](../../../demos/site/interactive.html#draggable-draggable).
- **Schema:** [draggable.schema.json](../../../src/wb-models/draggable.schema.json).
