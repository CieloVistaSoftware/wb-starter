# Pagination

The `x-pagination` behavior.

Apply `x-pagination` to any element.

## Usage

```html
<nav x-pagination total="100" per-page="10" current="5"></nav>
```

## Attributes read

- `total`
- `per-page`
- `pages`
- `current`
- `aria-disabled`
- `action`
- `page`
