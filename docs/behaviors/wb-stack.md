# wb-stack

A layout utility for stacking elements vertically with consistent spacing.

Wrapped in `<wb-demo>`, so the live component renders below with its source shown underneath:

<wb-demo>
<div class="wb-stack">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
</wb-demo>

- **Usage:**
  ```html
  <div class="wb-stack">
    <div>Item 1</div>
    <div>Item 2</div>
  </div>
  ```
- [Source](../../src/wb-viewmodels/wb-stack.js)
