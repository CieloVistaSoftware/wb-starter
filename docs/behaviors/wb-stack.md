# wb-stack

A layout utility for stacking elements vertically with consistent spacing.

Wrapped in `<wb-demo>`, so the live component renders below with its source shown underneath:

<wb-demo>
<wb-stack gap="1rem">
  <div>Item 1</div>
  <div>Item 2</div>
</wb-stack>
</wb-demo>
