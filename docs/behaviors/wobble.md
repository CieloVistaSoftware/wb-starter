# Wobble

The `x-wobble` behavior.

Apply `x-wobble` to any element.

## Usage

```html
<button class="effect-demo" x-wobble>Wobble</button>
```

## What it does

On click, plays the `wobble` animation for `1s` and removes it when it finishes.
