# Flip

On click, plays the flip animation for 0.6s.

## Type — new capability

`x-flip` adds behavior that no HTML element implies. Nothing about a tag says "ripple" or "tooltip", so this is always opted into by attribute, on whatever element you already chose.

### How to write it

```html
<button class="effect-demo" x-flip>
  x-flip
</button>
```
