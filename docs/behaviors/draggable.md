# Draggable

Make an element draggable.

Apply `x-draggable` to any element.

## Usage

```html
<div x-draggable>
  …
</div>
```

## Attributes

| Attribute | Values | Default | Description |
| --- | --- | --- | --- |
| `axis` | `x` · `y` · `both` | `both` |  |
| `handle` | `string` | — | Selector for drag handle |
