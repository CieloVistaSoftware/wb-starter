# Zoomin

The `x-zoomin` behavior.

Apply `x-zoomin` to any element.

## Usage

```html
<button class="effect-demo" x-zoomin>Zoomin</button>
```

## What it does

On click, plays the `zoom-in` animation for `0.4s` and removes it when it finishes.
