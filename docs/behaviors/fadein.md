# Fadein

The `x-fadein` behavior.

Apply `x-fadein` to any element.

## Usage

```html
<button class="effect-demo" x-fadein>Fadein</button>
```

## What it does

On click, plays the `fade-in` animation for `0.5s` and removes it when it finishes.
