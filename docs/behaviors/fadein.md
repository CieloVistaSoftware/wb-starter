# Fadein

`x-fadein` fades the element from transparent to fully visible over 0.5 s when it is clicked. The effect is clearest on content that has just been swapped in.

## Usage

<figure x-demo>
<button class="effect-demo" x-fadein>Click to fade in</button>
</figure>
