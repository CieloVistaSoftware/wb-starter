# Prompt

The `x-prompt` behavior.

Apply `x-prompt` to any element.

## Usage

```html
<button variant="primary" x-prompt prompt-title="Enter Value" prompt-message="Please enter your name:">Prompt Dialog</button>
```

## Classes applied

- `wb-prompt-trigger`

## Attributes read

- `prompt-title`
- `heading`
- `prompt-message`
- `message`
- `placeholder`
- `default-value`
