# Modal

The `x-modal` behavior.

## Type — new capability

`x-modal` adds behavior that no HTML element implies. Nothing about a tag says "ripple" or "tooltip", so this is always opted into by attribute, on whatever element you already chose.

### How to write it

```html
<div x-modal>
  …
</div>
```
