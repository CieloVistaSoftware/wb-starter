# Bounce

The `x-bounce` behavior.

Apply `x-bounce` to any element.

## Usage

```html
<button class="effect-demo" x-bounce>Bounce</button>
```

## What it does

On click, plays the `bounce` animation for `0.75s` and removes it when it finishes.
