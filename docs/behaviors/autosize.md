# x-autosize Behavior (deprecated)

> **Deprecated.** Use `<textarea autosize>` instead. Every `<textarea>` already
> grows with that attribute, and it also honors `maxRows`, which `x-autosize`
> does not. `x-autosize` still works and logs a one-time console warning.

Automatically resizes a textarea to fit its content as the user types.

<figure x-demo>
<textarea autosize placeholder="Type several lines — the box grows with them"></textarea>
</figure>
