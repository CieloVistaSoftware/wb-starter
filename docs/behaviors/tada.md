# Tada

On click, plays the tada animation for 1s.

## Type — new capability

`x-tada` adds behavior that no HTML element implies. Nothing about a tag says "ripple" or "tooltip", so this is always opted into by attribute, on whatever element you already chose.

### How to write it

```html
<button class="effect-demo" x-tada>
  x-tada
</button>
```
