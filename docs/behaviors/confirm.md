# Confirm

The `x-confirm` behavior.

Apply `x-confirm` to any element.

## Usage

```html
<button variant="primary" x-confirm confirm-title="Confirm Action" confirm-message="Are you sure you want to proceed?">Confirm Dialog</button>
```

## Classes applied

- `wb-confirm-trigger`

## Attributes read

- `confirm-title`
- `heading`
- `confirm-message`
- `message`
- `confirm-text`
- `cancel-text`
