# Pulse

The `x-pulse` behavior.

Apply `x-pulse` to any element.

## Usage

```html
<button class="effect-demo" x-pulse>Pulse</button>
```

## What it does

On click, plays the `pulse` animation for `0.5s` and removes it when it finishes.
