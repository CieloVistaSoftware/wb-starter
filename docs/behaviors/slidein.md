# Slidein

The `x-slidein` behavior.

Apply `x-slidein` to any element.

## Usage

```html
<button class="effect-demo" x-slidein direction="left">Slidein Left</button>
```

## What it does

On click, plays the `slide-in-<dir>` animation for `0.5s` and removes it when it finishes.
