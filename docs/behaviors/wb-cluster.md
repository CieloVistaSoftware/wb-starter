# wb-cluster

A layout utility for grouping elements with flexible alignment.

Wrapped in `<wb-demo>`, so the live component renders below with its source shown underneath:

<wb-demo>
<div class="wb-cluster">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
</wb-demo>

- **Usage:**
  ```html
  <div class="wb-cluster">
    <div>Item 1</div>
    <div>Item 2</div>
  </div>
  ```
- [Source](../../src/wb-viewmodels/wb-cluster.js)
