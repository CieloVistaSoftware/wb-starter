# Heartbeat

The `x-heartbeat` behavior.

Apply `x-heartbeat` to any element.

## Usage

```html
<button class="effect-demo" x-heartbeat>💓 Heartbeat</button>
```

## What it does

On click, plays the `heartbeat` animation for `1.3s` and removes it when it finishes.
