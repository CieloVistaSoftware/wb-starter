# Heartbeat

`x-heartbeat` scales the element up to 130% twice in quick succession, like a heartbeat, over 1.3 s when clicked. Suits a like or favourite button.

## Usage

<div x-demo>
<button class="effect-demo" x-heartbeat>♥ Like</button>
</div>
