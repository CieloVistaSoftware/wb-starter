🧩 WB Views System

Custom Element Factory: Define a template once → get a custom tag automatically. Change the template → ALL instances update.

One template definition, reused two equivalent ways, both producing the same output:

Custom elements require a hyphen (Web Components spec). WB Views handles this automatically:

View Name Has Hyphen? Custom Tag
toolbarNo<wb-toolbar> (auto-prefixed)
alert-boxYes<alert-box> (as-is)
stat-tileYes<stat-tile> (as-is)
nav-linkYes<nav-link> (as-is)

The Rule: No hyphen → auto-prefix with wb-  |  Has hyphen → use as-is
