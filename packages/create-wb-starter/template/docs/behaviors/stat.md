# Stat

`x-stat` shows one figure: a large `value` over a small `label`, with an optional colour `variant`. Use `x-cardstats` when you want it inside a card with a trend.

## Usage

<div x-demo>
<div x-stat value="1,284" label="Builds this month"></div>
</div>

## Classes applied

- `x-stat`

## Attributes read

- `value`
- `label`
- `variant`
