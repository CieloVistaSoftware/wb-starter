# x-demo

A wrapper for demoing behaviors or behaviors: it renders the **live control** and
shows its **source** underneath. Drop it straight into a Markdown doc or an HTML
page — no build step.

## Live example

<div x-demo>
  <button variant="primary">Button</button>
</div>

The block above is a real `<div x-demo>` embedded in this Markdown — the button you see
is live, and its source is rendered beneath it.

## Syntax

```html
<div x-demo>
  <button variant="primary">Button</button>
</div>
```
