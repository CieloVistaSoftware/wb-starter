# x-stack

A layout utility for stacking elements vertically with consistent spacing.

Wrapped in `<div x-demo>`, so the live component renders below with its source shown underneath:

<div x-demo>
<div x-stack gap="1rem">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
</div>
