# Slider

`x-slider` currently only adds the `x-slider` class; it does not build an image comparison or carousel, and no stylesheet targets the class. Put on a range `<input>` it leaves the native slider as it is.

## Usage

<div x-demo>
<input x-slider type="range" min="0" max="100" value="35">
</div>
