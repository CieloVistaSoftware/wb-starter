# Ratio

Behavior applied with x-ratio.

Apply `x-ratio` to any element.

## Usage

```html
<div x-ratio ratio="16:9">
  <img src="https://picsum.photos/seed/wide/640/360" alt="Coastline from the air">
</div>
```
