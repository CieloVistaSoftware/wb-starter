Questions

How do I add a page?

Create pages/contact.html, then add { "menuItemId": "contact", "menuItemText": "Contact", "pageToLoad": "contact" } to navigationMenu in config/site.json.

How do I publish it?

Run npm run build and upload the dist/ folder to any static host, such as GitHub Pages.
