Harmonic Color System

Every theme is built on wave-based color mathematics for perfect harmony

🌊 Wave-Based Color Derivation

Colors are derived using wave frequencies. The primary hue acts as the fundamental frequency, with secondary and accent colors as harmonics.

Primary 240°
Secondary 60° (+180°)
Accent 210° (-30°)

Color Harmony Types Used in Themes

Complementary

Opposite colors on the wheel (180° apart)

Secondary = Primary + 180°

Used in: Dark, Light

Analogous

Adjacent colors on the wheel (±30°)

Colors = Primary ± 30°

Used in: Ocean, Midnight

Triadic

Three colors equally spaced (120° apart)

Colors = Primary + 0°, 120°, 240°

Used in: Sunset, Aurora

Split-Complementary

Primary + two adjacent to complement

Colors = Primary, (Primary+180°)±30°

Used in: Forest, Twilight

📐 The Mathematics

Wave Frequency Formula

f = c / λ

Color hue mapped to wave frequency. Primary color establishes the base frequency.

Harmonic Relationship

Hn = H1 × n

Secondary and accent colors derived as harmonic multiples of primary.

Lightness Derivation

L = 50% + (amplitude × sin(θ))

Light/dark variants calculated using sine wave amplitude modulation.

Implementation Example

```javascript // Harmonic Color System - Theme Generation function generateHarmonicPalette(primaryHue, harmonyType = 'complementary') { const palette = { primary: primaryHue }; switch (harmonyType) { case 'complementary': palette.secondary = (primaryHue + 180) % 360; palette.accent = (primaryHue - 30 + 360) % 360; break; case 'analogous': palette.secondary = (primaryHue + 30) % 360; palette.accent = (primaryHue - 30 + 360) % 360; break; case 'triadic': palette.secondary = (primaryHue + 120) % 360; palette.accent = (primaryHue + 240) % 360; break; case 'split-complementary': palette.secondary = (primaryHue + 150) % 360; palette.accent = (primaryHue + 210) % 360; break; } return palette; } // Example: Generate Ocean theme (Analogous Blues) const oceanPalette = generateHarmonicPalette(200, 'analogous'); // Result: { primary: 200, secondary: 230, accent: 170 } ```

How to Use Themes

Simple implementation with CSS custom properties

1. Set Theme Attribute

<html data-theme="ocean"> ... </html>

2. Switch via JavaScript

// Switch theme programmatically document.documentElement .setAttribute('data-theme', 'cyberpunk');

3. Use CSS Variables

.my-behavior { background: var(--bg-secondary); color: var(--text-primary); border: 1px solid var(--border-color); }
