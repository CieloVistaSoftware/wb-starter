🆕 What's New

What's actually live on this site right now — every push to main deploys straight to cielovistasoftware.github.io/wb-starter, so this list is the real changelog, not a promise of a future release.

2026-08-03

  • Fixed docs/manifest.json 404ing on the root SPA (/index.html) — every component's "Docs:" link on the main site was silently dead.
  • 45 components (<wb-card>, <wb-button>, <wb-badge>, and more) no longer carry a redundant CSS class that just repeated their own tag name.
  • Fixed WB.scan() never processing the exact element passed to it (only its descendants) — this was silently breaking syntax highlighting, line numbers, and the copy button on every dynamically-injected code panel site-wide.
  • Framework Integration Demo: removed a legacy, duplicate code-highlighting system that was clipping the left edge of every code sample; Svelte and SolidJS examples now compile and render live in the browser (Angular can't without a real build step — explained why, on the page).
  • Playground: the 20-video YouTube example now grids 3-per-row instead of one huge column; sample form labels now sit above their field instead of beside it.
  • The site's browser-tab title and social-share preview card showed generic placeholder text ("My Awesome Site") instead of real branding — fixed, with proper preview images added.
  • Fixed flat, non-responsive page padding eating up to 38% of small phone screens across 11 pages — a full-width hero image was reading as a narrow strip because of it.
  • Every clickable button, card, and switch across the demo pages now shows a quick confirmation toast when clicked.
  • Card Components demo: added a theme picker, and replaced placeholder links/identity (generic example.com URLs, a stock "Jane Doe") with real destinations.
  • Fixed the profile card's role badge sitting visibly off-center on its cover photo (a repeat of an earlier "fix" that didn't actually center it).
  • Fixed the theme picker silently duplicating itself into two out-of-sync dropdowns over a long browsing session.
  • Removed several redundant x-fieldset/x-form attributes that were already automatic — added a test that catches this pattern going forward.

2026-08-02

  • Fixed <wb-input> rendering no real <input> element at all on any standalone demo page (32 broken instances on the Form Controls page alone) — the schema-driven markup it depends on was never built under this site's lazy-loading runtime. It's now constructed directly, matching how other components already handle this.
  • Fixed the theme picker breaking syntax-highlighting colors site-wide on any page that includes it — it was resolving to a dev-only file path that doesn't exist in production.
  • Fixed silent failures across the site being swallowed instead of shown — component errors now surface in the visible error log instead of vanishing into the console.
  • <wb-button icon="..."> now throws a clear error (with a link to the icon list) if set but left empty, instead of silently rendering no icon.
  • Fixed <wb-audio> silently doing nothing on a missing/empty file — it now throws a clear error, and 8 broken audio examples on the Content page were pointed at a real audio file.
  • Fixed the Shop Now / Learn More buttons on the Card Components hero demo, and the pricing/portfolio CTA buttons on Card Components and the main Components page — all had no destination before today.
  • Fixed the theme picker showing up twice (unsynced) on some pages — consolidated to one, in the site header.
  • Fixed the doc-link icon disappearing on the home page hero card, a role badge sitting too low on profile cards, the avatar status dot being too small, a dropdown menu getting clipped when it opened upward, an input field showing three stacked borders instead of one, and the date/time picker icon being invisible in dark mode.

2026-08-01

  • Fixed <wb-select> silently discarding real <option> children — every documented example (<wb-select><option>...</option></wb-select>) rendered an empty dropdown with only the placeholder.
  • Fixed <wb-draggable>/x-draggable jumping to a wildly wrong position on every drag instead of tracking the mouse — and getting worse with each subsequent drag. Also fixed axis="x"/axis="y", which never actually constrained movement.
  • The Behaviors page no longer mixes in 15 full wb-* component demos (alerts, badges, progress bars, spinners, modals, drawers, tabs, accordion, audio player, switch, rating) — it's scoped back to genuine x-* attribute behaviors, with links to the Components page for the rest.
  • Fixed the deprecated <wb-checkbox>/<wb-textarea> wrapper elements on the Form Controls demo page — converted to native <input type="checkbox">/<textarea>, which already get the same styling with no wrapper needed.
  • The home page no longer eagerly fetches the entire page-builder partial library (20+ files) on load — those now load lazily, only when a page actually uses one.
  • <wb-demo>'s code sample panel now scrolls horizontally instead of wrapping, and spans full width on mobile (≤700px) so scrolling past a page of demos doesn't jitter the page width — desktop still hugs each demo's own content.
  • Added a size attribute to x-gallery for fixed-size thumbnails (e.g. size="150px"), independent of the columns count.

2026-07-30

  • Fixed a sanitizer bug in the markdown renderer that silently ate any attribute whose name contained "on" followed by more letters before its own = (e.g. options='...') — this was corrupting JSON-in-attribute examples site-wide, including live <wb-select> dropdowns that quietly lost all their options.
  • Fixed <wb-cardportfolio>'s variant, size, and availability-status indicator — none of them had any visible effect before today.
  • Fixed <wb-timeline> not rendering at all (missing a base display: block).
  • Fixed <wb-drawer> on standalone demo pages: it showed generic placeholder text instead of its real content, "top"/"bottom" positions rendered identically to "left", and the variant attribute (default/overlay/push) had no effect at all.
  • Fixed <wb-dropdown>: position values didn't match the real attribute names so every position looked the same, menus opened empty when using plain text content, and trigger="hover" never actually worked.
  • Fixed progress bars and other enum-variant showcase pages rendering at 0%/invisible because the demo generator never filled in a representative value.
  • Added a real button-like appearance (background, border, cursor) to dialog/drawer/dropdown triggers that previously looked like plain unstyled text.
  • Fixed inline code chips and code blocks wrapping mid-word instead of scrolling or breaking at real word boundaries, on the Components page and the frameworks demo.
  • Every demo's "read the docs" link now sits as a small badge in the component's own top-right corner instead of a detached line below the whole group.
  • Converted every remaining static code example on the Select doc page and the full Behavior Cross-Reference doc (159 examples) into live, rendered demos.
  • Fixed 8 standalone demo pages that had zero padding, so headings and text sat flush against the browser edge.
  • Closed out a large batch of compliance-gate debt: reduced excess !important CSS usage back under the project's own limit, fixed a broken page-fragment generator that was shipping full HTML documents where the app expected bare fragments, fixed 10 pages' stylesheet links that 404'd under this site's actual deployed URL, and cleared out stale px-to-rem and data-attribute audit failures.

2026-07-29

  • Fixed a Playwright-suite-wide "app ready" race: dozens of tests waited on the WB object existing, which is true before the app actually finishes initializing — now they wait for the real ready signal.
  • Restored the Behaviors page's missing content (spinner, and more) by regenerating it from its own schema, and fixed two stale button/alert markup patterns flagged by the compliance gate.
  • Rewrote a large batch of stale, pre-broken tests (dead entry points, renamed files, old CSS class names) so they test what the code actually does today.
  • Added margins/padding to the Card Components demo page and restored a missing closing </html> tag.
  • Added this "What's New" page.

2026-07-28

  • Split the Card Components demo page apart from its 56-card permutation test matrix — the demo page loads faster and the matrix now has its own dedicated test fixture.
  • Deprecated <wb-checkbox>/<wb-textarea> in favor of native <input type="checkbox">/<textarea> with attributes — no more reinventing what the browser already does.
  • Fixed the Playground's "Endpoint sees" panel showing unconditionally instead of respecting its hidden state.
  • Fixed a 404 in the code-highlighting fallback loader.
  • Fixed <wb-search> never getting its variant/size CSS classes.
  • Fixed cardhero variants, cardproduct badges, a lazy-demo scanning bug, an error-log race condition, and button-transition test flakiness.
  • Fixed lightbox, alert variants, countdown, YouTube embeds, and a cardimage race condition that made valid images falsely show "unavailable."

Week of 2026-07-14 – 18

  • Consolidated demo pages into 8 clear categories, up from a sprawling flat index.
  • Fixed dispatch collisions where multiple behaviors fought over the same host element (switch, checkbox, select, textarea, input, button).
  • Added just-in-time CSS loading for behaviors — no more shipping every behavior's stylesheet on every page.
  • Fixed a CLS (layout shift) regression in the grid layout.
  • Added a selectable debug-trace category filter for easier troubleshooting.
