🆕 What's New

What's actually live on this site right now — every push to main deploys straight to cielovistasoftware.github.io/wb-starter, so this list is the real changelog, not a promise of a future release.

2026-08-19

  • Behaviors showcase rebuilt around a live selector. Pick any behavior or variant from the list and it renders immediately beside the list, with its formatted source, its live events, the handler you would copy, and its docs — replacing the 88 hand-written demo sections that used to run down the page (#664, #666).
  • <wb-table paginated> now paginates. paginated and pageSize were declared in the schema and read nowhere, so the attribute rendered every row and no controls. Rows are hidden rather than removed, so sorting, searching and row listeners keep working on the same nodes. hoverable and filterable — the documented spellings — did nothing either, because the behavior only ever read hover and searchable; both are accepted now (#669).
  • Form control variants are visible again. <textarea variant="error"> applied the right class and the CSS rule was correct, yet every variant looked identical to plain. Two causes, both fixed: the behaviors set border/background/color inline, which beats any stylesheet rule, so each one overrode its own variant classes; and the bare-native rules in input.css stacked up to nine :not([type=…]) selectors, outranking a modifier class on specificity. wb-input--warning was applied by the behavior but no rule ever defined it (#671).
  • Native <select> honours variant and size. The behavior early-returned for a native <select>, handling only clearable, so <select variant="error"> came out with no class at all. A numeric size="4" deliberately keeps its native "show 4 rows" meaning instead of becoming a style class (#681).
  • Behaviors no longer destroy your content. <div x-cardbutton>Example content</div> rendered an empty card — the text was wiped before the body was built. A sweep of all 105 x-* behaviors found 21 doing this; it is now 10, and all 19 card behaviors keep their content in both the <wb-*> tag and x-* attribute forms. Also closed a broader gap: the schema exclusion list that protects behaviors from being wiped was consulted only for <wb-*> tags, so every entry on it was bypassed by the equivalent x-* attribute (#678).
  • The upload demo actually uploads. Nothing in the codebase could send a file — the "Upload a file" control was a picker. It now does a real round trip with progress and reports what the server received. Uploads are accepted and discarded, never stored (#676).
  • The documentation panel no longer vanishes for the 116 of 143 behaviors that have no .md — it says so instead of disappearing (#673).
  • Every element in the showcase carries a stable id, and the event log names the element an event actually came from, so two events from different elements are no longer identical lines (#675, #677).
  • Striped table rows have real contrast — only the odd rows were painted, leaving the even ones transparent, so the stripe depended on whatever surface the table happened to sit on rather than on the theme (#672).
  • Generated samples emit real children for elements that require them — <select> was being handed bare text, which is not selectable, so it rendered an empty control (#681).
  • Fixed 24 dead documentation links: wrong directory depth, behaviors referenced under names they never had (column/row/stack all live in layouts.js), and paths still pointing at the retired src/styles/components/ tree.
